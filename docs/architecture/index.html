Welcome to the central architectural hub for Vedha AI. All design blueprints, component hierarchies, low-level implementation details, distributed system protocols, and architectural decision records are organized here in rich, visual, self-contained HTML documents.

💡 Human-First Engineering Principle

Every architecture file in this directory follows a strict dual-layer standard: Human-First Plain-English Clarity so any team member immediately grasps the fundamental concepts, paired with Exhaustive Deep Engineering (CQRS contracts, entity relationships, NATS streaming queues, and container topologies) so engineers can build and verify systems with complete precision.
