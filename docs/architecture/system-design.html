System Design & Distributed Infrastructure Architecture

This document details the distributed runtime topology, asynchronous event streaming pipelines, database schema design, object storage topologies, anti-bot scraping sidecars, and operational failure modes that comprise the Vedha AI production ecosystem.

💡 Plain-English Summary: What is System Design?

System Design explains how multiple independent computers, servers, databases, and background robots work together without stepping on each other's toes. Think of an international airport: you have passport control (our Auth service), baggage sorting (our S3 storage), flight radar (our NATS message bus), and airplanes taking off (our AI scrapers). Everything must communicate reliably, even if one service restarts or a website tries to block our bot.

1. Distributed Architecture Overview

Vedha AI is architected as an Event-Driven Micro-Service Mesh deployed via Docker Compose in the infra/ folder. The system separates interactive user traffic (HTTP REST/SignalR) from heavy, unpredictable background tasks (headless web crawling, AI tailoring, document rendering) using an asynchronous NATS JetStream message bus.

3. Asynchronous Event Streaming with NATS JetStream

To prevent HTTP request timeouts when processing complex documents or navigating multi-page job postings, tasks are published to JetStream queues.

Stream Configuration (VEDHA_STREAM)

Retains messages with FileStorage mode. Subjects: crawler.jobs, tailor.jobs, and copilot.events. Enforces at-least-once delivery with durable consumer groups.

Poison Pill Protection & Dead-Letter Handling

Consumers configure MaxDeliver: 3 and AckWait: 30s. If an unparseable job posting crashes the parser 3 times, the message is automatically routed to deadletter.jobs.

6. MinIO S3 Object Topologies

Binary documents are segregated across dedicated buckets:

  • master-resumes/: Original user PDF and DOCX uploads before parsing.
  • tailored-resumes/: Clean, rendered PDF resumes generated by QuestPDF.
  • exports/: Markdown and Word documents with 15-minute temporary pre-signed download URLs.

7. Anti-Bot Stealth Architecture (ADR-004)

The dedicated vedha-crawler container uses Crawl4AI to bypass enterprise anti-bot defenses:

Browser Fingerprint Spoofing

Modifies navigator properties (navigator.webdriver = false), randomizes canvas noise, and normalizes viewport dimensions to mirror real macOS/Windows Google Chrome installations.

Dynamic Accordion Unrolling

Injects custom JavaScript hooks to locate and click "See more" and "Show full job description" buttons before stripping navigation menus and extracting clean Markdown. JobPostingTitleParser then separates the job title from a career-page motto so Company | motto is never saved as the target role.

8. Security Threat Modeling & Operational Resilience

Security Invariants

• JWT keys stored in environment variables (never committed to Git).
• OWASP-compliant password hashing.
• Pre-signed S3 download URLs expire after 15 minutes.
• Cross-origin postMessage restricted strictly to verified origin.

Fault Recovery & Self-Healing

• restart: unless-stopped on all Docker services.
• NATS consumer dead-letter queue isolation.
• Automatic 3-tier scraping fallback (Crawl4AI -> Playwright -> AngleSharp).
• Automatic metric violation rollback to candidate master resume.

9. Aksh Agentic Execution Topology & Token Ledger Infrastructure

Aksh introduces an interactive agent plane operating alongside the existing asynchronous NATS queue pipeline:

Real-Time Server-Sent Events (SSE) Stream

Client connections to /api/aksh/sessions/{id}/messages stream high-density JSON events (session, plan, status, message deltas, approval-request, ledger, and done) over HTTP/1.1 or HTTP/2 chunked transfer encoding, giving immediate candidate visibility into agent reasoning and tool executions.

Token Ledger & Daily Budget Governor

Every turn and tool invocation logs input/output tokens to AkshSessions and the token ledger audit table. Hard daily quotas (Aksh:DailyTokenBudget) auto-pause runs on budget breach, protecting candidate API quotas and preventing unbounded agent execution loops.
