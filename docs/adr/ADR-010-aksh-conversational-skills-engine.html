Architecture decisions · ADR-010

Dual-Mode Conversational Chatbot & Prompt-Adaptive Dynamic Skill Routing

ACCEPTED Agent Architecture Full-Stack Aksh 2026-10-28
Human-First Summary. Aksh AI is transformed into a natural, conversational career chatbot capable of open-ended discussion, strategic mentorship, behavioral STAR interview coaching, salary negotiation advice, and resume critique—without forcibly executing tools or getting stuck in a rigid multi-step pipeline. Based on the candidate's prompt, Aksh dynamically detects intent, activates the optimal specialized skill, streams real-time contextual prompt chips to the UI, and responds conversationally in rich Markdown.

Context & Problem Statement

Originally, Aksh AI was designed as a strict harness execution agent under the constraint: "The harness injects todo/plan/execute tools — these instructions bind them into a strict order so the model acts instead of chats." While effective for automated job application pipelines, this created three critical limitations:

  • Robotic Execution Resistance: When a candidate asked general questions (e.g., "What is the STAR method?", "How does leveling work between Staff and Principal?", or "Hi, how can you help me?"), the model felt forced to invoke tools (like get_master_resume or todos_add) or apologized for not executing actions, degrading the user experience.
  • Keyword Collisions & False Pipeline Triggers: Intent matching checked for substrings like "apply" without word boundaries. Asking "What is the status of my application?" or "Can you apply the XYZ formula to my resume?" inadvertently matched HasApplyIntent and triggered the autonomous apply pipeline instead of queue auditing or resume optimization.
  • Cross-Turn URL Pollution: Pasting a job URL in turn 1 contaminated the session string buffer in subsequent turns, causing later conversational questions to re-scrape or attempt re-packaging.

Architecture Decision & Flow

1. Dual-Mode Persona Architecture

In AkshPrompts.cs, instructions now explicitly establish dual capabilities:

  • Conversational Chatbot Mode: When candidates greet, explore options, ask conceptual questions, or request advice, the model responds directly in rich Markdown without forcing tools or executing pipeline tasks.
  • Autonomous Action Copilot Mode: When a job URL is provided or the candidate explicitly instructs Aksh to tailor, prepare, or apply, the model enters the PLAN -> GROUND -> ACT -> REPORT -> GATE pipeline.

2. Dynamic Skill Priority Hierarchy

AkshSkillRegistry reorders skill resolution so that specific domain queries always resolve to their dedicated expert skills before falling into the autonomous application copilot:

Priority Skill Identifier Domain Focus Sample Triggers
1 profile-queue-audit Applications, statuses, screening memory, work auth "What is the status of my applications?", "Where did I apply?"
2 platform-navigator Vedha AI features, extension, review gateway, settings "How do I use the Chrome extension?", "Where do I configure Gemini?"
3 interview-coach STAR behavioral answers, system design drills, mock interview "Conduct a mock interview", "STAR behavioral questions"
4 salary-negotiator Total compensation benchmarks, counter-offer scripting "How do I negotiate my counter offer?", "RSU vesting cliff"
5 resume-optimizer Google XYZ impact bullets, ATS keyword gaps, tailoring "Optimize my resume bullets", "Apply XYZ formula to my resume"
6 job-application-copilot Autonomous job application pipeline, Review Gateway staging Pasted job URLs, "Apply to this role", "Auto-apply"
7 career-strategist General career mentorship, tech transitions, greetings "Hi", "Staff vs Principal difference", "Tech roadmap"

3. Dynamic Contextual Prompt Chips (`SuggestedChips`)

Each skill implementation exposes a curated list of prompt chips. The SSE skill event streams these chips to the frontend, rendering a horizontal quick-action tray directly above the chat composer in AskAkshPage.tsx. Clicking any chip immediately delivers the prompt.

4. Pure Current-Turn URL Extraction

In AkshAgentRunner.cs, URL scraping is isolated strictly to URLs found in the candidate's current turn message (AkshIntent.ExtractJobUrls(cleanMessage)), preventing old job links from hijacking new conversational turns.

Consequences & Verification

  • Natural Conversations: Aksh chats warmly and answers complex career, technical, and platform questions immediately without tool stalls.
  • Zero Regression on Autonomous Application: Pasting a job URL or requesting application immediately engages the full truth-checked package preparation and Review Gateway approval gate.
  • Test Verification: All 225 unit tests in ResumeTailor.UnitTests passed 100%, and all 156 E2E tests in tests/e2e/runner.js passed 100%.
